# 🛠️ Sensor Calibration & Troubleshooting Guide

This guide provides step-by-step instructions for calibrating sensors, eliminating false positives, and troubleshooting connectivity or power issues for the **ESP8266 Infant Safety Monitoring System**.

---

## 1. 🌡️ DHT11 Temperature & Humidity Sensor Calibration

### Calibration & Best Practices
- **Sampling Frequency**: Do not query the DHT11 sensor faster than once every 2 seconds (`SENSOR_READ_INTERVAL >= 2000ms`). Polling faster leads to internal self-heating and inaccurate temperature spikes.
- **Pull-Up Resistor**: Ensure a **4.7kΩ to 10kΩ pull-up resistor** is connected between the DHT11 Data line (ESP8266 `D5`) and `3.3V` if using a standalone 3-pin DHT11 module without built-in pull-ups.
- **Location**: Position the DHT11 sensor away from the ESP8266 microcontroller body to prevent heat dissipation from the ESP8266 Wi-Fi chip from skewing room temperature measurements.

### Troubleshooting Table
| Symptom | Probable Cause | Recommended Action |
| :--- | :--- | :--- |
| `Failed to read from DHT11 sensor!` | Loose wiring or missing pull-up resistor | Check jumper wires on `D5` (GPIO 14) and verify 3.3V power rail. |
| Temperature reads 5-10°C too high | Sensor placed too close to ESP8266 board | Move sensor 10-15 cm away using flexible ribbon cables. |
| Humidity stuck at 0% or 99% | Sensor element saturated or damaged | Power cycle unit or replace DHT11 module. |

## 2. 🔊 Analog Sound Sensor Calibration & Noise Floor Baseline

### Potentiometer Adjustment Procedure
1. **Set Baseline**: Place the sound sensor module in the target room under silent ambient conditions.
2. **Adjust Gain Potentiometer**: Using a small Phillips screwdriver, rotate the blue multi-turn potentiometer on the sound sensor module until the module's onboard LED indicator just turns OFF.
3. **Verify Trigger Threshold**: Create a sample baby cry or clap sound at a distance of 1-2 meters. The onboard indicator LED should flash synchronously with the noise.
4. **Tune Software Threshold (`V7`)**: Use the Blynk mobile slider widget (`V7`) to fine-tune `SOUND_THRESHOLD` (typically set between `650` and `800` out of `1023`).

### Preventing False Crying Alerts
- **Peak Smoothing**: The code applies an Exponential Moving Average (EMA) and multi-sample peak buffer to discard sudden single-millisecond acoustic pops or room door clicks.
- **Power Decoupling**: Connect a `10µF` electrolytic capacitor across `VCC` and `GND` near the sound sensor module to absorb supply voltage ripples generated by ESP8266 Wi-Fi transmission bursts.

## 3. 🚶 PIR Motion Sensor Fine-Tuning (HC-SR501)

### Hardware Controls
- **Sensitivity Potentiometer (`Sx`)**: Adjust clockwise to increase range (up to 7 meters) or counter-clockwise for short-range detection (approx 3 meters) around the crib.
- **Time Delay Potentiometer (`Tx`)**: Rotate fully counter-clockwise to minimize trigger hold duration (approx 3 seconds) for quick resetting.
- **Trigger Mode Jumper**: Set jumper to **H (Repeat Trigger mode)** so continuous infant movement keeps the output HIGH without dropping LOW intermittently.

## 4. 💾 EEPROM Memory Diagnostics & Factory Reset

### Restoring Default Threshold Settings
If incorrect threshold values were pushed via Blynk and saved to persistent EEPROM memory, perform a manual memory reset:

1. Open `esp8266_baby_monitor.ino`.
2. Temporarily change `EEPROM_MAGIC` to a different 16-bit hex value (e.g. `0xB4B1`).
3. Re-compile and upload the sketch to force EEPROM re-initialization to default safety limits:
   - `MIN_TEMPERATURE`: `18.0 °C`
   - `MAX_TEMPERATURE`: `30.0 °C`
   - `SOUND_THRESHOLD`: `700`

## 5. 🌐 Wi-Fi & Blynk Connection Diagnostics

| Serial Monitor Output | Diagnosis | Solution |
| :--- | :--- | :--- |
| `WiFi connection failed!` | Incorrect SSID/Password or 5GHz Wi-Fi | ESP8266 only supports 2.4GHz Wi-Fi networks. Split SSID bands in router settings. |
| `[COOLDOWN] Notification skipped` | Alert triggered within 60s window | Normal operation preventing push alert spam. Adjust `NOTIFICATION_COOLDOWN` in code if needed. |
| `[ERROR] Blynk disconnected!` | Invalid Auth Token or cloud server unreachable | Re-copy `BLYNK_AUTH_TOKEN` from Blynk Console settings. |
